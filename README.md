# Week 7 Assignment: My Notes & The Report Builder

This repository contains my PLP Python Week 7 assignment.

## Files

- `my_notes.py` — Writes three notes, appends a fourth note, reads the notes, and counts the lines.
- `my_notes.txt` — The text file generated by the notes program.
- `report_builder.py` — Reads learner data from a CSV, calculates pass/fail totals and the average, and writes a report.
- `hubs.csv` — Learner names, hub names, and scores used by the report builder.
- `report.txt` — The generated learner report.

## What happens if `"a"` is changed to `"w"` in Question 1?

Changing append mode (`"a"`) to write mode (`"w"`) would erase the existing contents of `my_notes.txt` before writing the fourth note. The first three notes would be lost, leaving only the fourth note in the file.
